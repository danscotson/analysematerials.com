About Analyse Materials

Transparent, practical software for materials characterisation.

Analyse Materials is an umbrella platform for software tools that support materials characterisation, microscopy analysis, diffraction visualisation and reproducible research.

Many materials analysis workflows rely on a mixture of software and ignore the importance of communicating these results. Analyse Materials software combines analysis and visualisation to extract more value from your datasets.

Current focus

  • Microscopy image analysis
  • X-ray diffraction visualisation
  • Scientific figure preparation
  • Materials data workflows
